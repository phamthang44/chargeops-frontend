# chargeops-owner-web (planned)

Station-owner client. Per the SRS this is a **React Native mobile app** (the owner manages their
station from a phone), despite the `-web` folder name. Not started yet.

Scope (SRS FR10, FR11, FR12, revenue dashboard): station registration, charger & time-slot
management, pricing configuration, booking oversight, revenue dashboard. Follows the shared
[`../DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md) and the service-layer + design-token architecture.
